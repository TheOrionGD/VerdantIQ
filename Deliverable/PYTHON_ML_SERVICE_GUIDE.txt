================================================================================

1. WHAT IS THE PURPOSE OF THE PYTHON SERVICE?
--------------------------------------------------------------------------------
The Python service lives in `./ml-service/` and runs on PORT 8000.
It handles:
  - XGBoost Behavioral Consumption Forecasting (`/api/v1/ml/forecasts`)
  - Scikit-learn Anomaly Detection & Explainable AI (`/api/v1/ml/explain`)
  - Google OR-Tools MILP Constraint Solver (`/api/v1/optimizer/solve`)
  - Model Retraining Pipeline (`/api/v1/ml/retrain`)

3. ENVIRONMENT VARIABLES (in ml-service/.env)
--------------------------------------------------------------------------------
All sensitive keys and connection strings MUST be kept in `ml-service/.env`:

PORT=8000
HOST=0.0.0.0
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/ecosphere?retryWrites=true&w=majority
SPRING_BOOT_API_URL=http://localhost:8080/api/v1
GROQ_API_KEY=gsk_your_groq_api_key_here


4. HOW TO RUN THE PYTHON FASTAPI SERVICE
--------------------------------------------------------------------------------
1. Navigate to the ml-service directory:
   cd ml-service

2. Create a Python Virtual Environment:
   python -m venv venv

3. Activate the Virtual Environment:
   - Windows (PowerShell): .\venv\Scripts\Activate.ps1
   - Windows (CMD):        .\venv\Scripts\activate.bat
   - Linux/macOS:          source venv/bin/activate

4. Install Dependencies:
   pip install -r requirements.txt

5. Start the Server:
   uvicorn app.main:app --reload --port 8000

6. Interactive API Documentation (Swagger UI):
   Open http://localhost:8000/docs in your browser.
